Dashboard Admin

Prototype admin ini menyimpan data di browser lokal. Untuk versi produksi, data perlu dipindahkan ke database.

Cara Pakai

Gunakan tombol pintas di atas untuk masuk ke menu yang ingin dikelola. Setelah menambah atau mengedit data, klik simpan lalu buka halaman publik pada browser yang sama untuk melihat perubahan.

Upload gambar pada prototype dapat memakai tombol upload atau URL gambar. Ukuran upload maksimal sekitar 900 KB. Untuk file lokal permanen, letakkan gambar di folder images, lalu isi misalnya images/foto-kegiatan.jpg.
